A PDF's ingestion pipeline moves through four states visible in the UI (`pending` → `processing` → `completed`/`failed`): text is extracted, split into overlapping chunks so context isn't lost between fragments, embeddings are generated, and everything is indexed with an HNSW index so semantic search stays fast even with many materials.

The analytics panel aggregates per-course metrics (materials, enrollments, popularity) and cohort distribution, useful for a coordinator to see the overall state without running manual database queries.
