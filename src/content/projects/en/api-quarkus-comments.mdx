The frontend lives in a separate repository: [InterfazGraficaPrimerfaces](https://github.com/jairocodes/InterfazGraficaPrimerfaces). It talks to the API purely over HTTP through an environment variable (`API_BASE_URL`), which lets each part be deployed and versioned independently.

The daily report email goes out through Resend over SMTP, and both the CSV output path and the report recipient are configurable via environment variable instead of being hardcoded.
