El frontend vive en un repositorio separado: [InterfazGraficaPrimerfaces](https://github.com/jairocodes/InterfazGraficaPrimerfaces). Se comunica con la API únicamente por HTTP mediante una variable de entorno (`API_BASE_URL`), lo que permite desplegar y versionar cada parte de forma independiente.

El envío de correo del reporte diario usa Resend por SMTP, y tanto la ruta de salida del CSV como el destinatario del reporte son configurables por variable de entorno en vez de estar fijos en el código.
