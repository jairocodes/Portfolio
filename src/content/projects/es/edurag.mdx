El pipeline de ingesta de un PDF pasa por cuatro estados visibles en la UI (`pending` → `processing` → `completed`/`failed`): se extrae el texto, se divide en chunks con solapamiento para no perder contexto entre fragmentos, se generan embeddings, y se indexan con un índice HNSW para que la búsqueda semántica en la consulta RAG sea rápida incluso con muchos materiales.

El panel de analíticas agrega métricas por curso (materiales, inscripciones, popularidad) y distribución por cohorte, útil para que un coordinador vea el estado general sin hacer consultas manuales a la base de datos.
